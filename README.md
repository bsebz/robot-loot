# ROBOT LOOT

Jeu pixel art 2D low-rez, vue top-down.

Robot gris, yeux cyan, joints or, antenne.
Ramasse OR, ENERGIE, CRISTAUX. Achète des upgrades au magasin. Build des tourelles, murs, etc.

## Jouer

Le jeu est un fichier HTML autonome : `index.html` (ou `robot-loot.html`).

Pour jouer en ligne via GitHub Pages :
1. Upload `index.html` (copie de robot-loot.html) à la racine.
2. Settings > Pages > Source : Deploy from branch main / root.

URL : https://bsebz.github.io/robot-loot/

Sprites : gris, cyan eyes, gold joints, antenna. Aimant = fer à cheval rouge.
